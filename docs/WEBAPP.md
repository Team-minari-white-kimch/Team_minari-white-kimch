# 웹앱: 새내기 농부 비서

로그인 없이 바로 쓰는 모바일 우선 웹앱이다. 빌드 없이 정적 파일(`index.html`, `app.js`, `data.js`, `styles.css`)로 동작해 지금 연결된 Azure Static Web Apps 배포에 그대로 올라간다.

## 화면

| 탭 | 기능 | 데이터 |
|---|---|---|
| 오늘 | 7일 날씨, 서리·관수·탄저병·미나리 수위·밑거름 안내(근거 표시), 승인한 일정, 해당될 수 있는 지원사업 | Open-Meteo 실시간 예보 → 실패 시 `seed/forecast-cheongdo-20261105.json`, `seed/programs.json` |
| 진단 | 사진 + 보이는 특징 → 후보 최대 3개, 확신 정도, 근거, 관리법, 검증에서 뺀 후보, 기록 저장 | `data.js` 병해충 참고 정보, 사진 색 분석(간이), 날씨 |
| 기록 | 영농 기록, 다음 할 일 제안(승인 후 추가), 일정 완료·삭제, 브라우저 알림 | 이 기기 저장소 |
| 농기계 | 면적·작업별 추천, 청도 임대사업소 3곳, 대여·반납 일정 기록 | 기사·공공데이터 출처 |
| 커뮤니티 | 노하우·질문 글, 주제 필터, 검색, 댓글, 도움돼요, 신고·숨기기, 질문하면 관련 선배 노하우 모아 보기, 전화번호 자동 가림 | 이 기기 저장소 + 예시 글 |

## 지금의 한계

- **AI 모델 미연결:** 진단과 노하우 모아 보기는 앱 안의 규칙으로 동작한다. `/api/diagnose`, `/api/community/ask`가 생기면 앱이 먼저 그쪽을 부른다.
- **커뮤니티 저장:** 글은 각 기기 브라우저에만 저장된다. 여러 사람이 함께 보려면 API와 저장소(예: Azure Table Storage)가 필요하다.
- **사진 진단:** 사진은 색·흐림 정도만 분석한다. 이미지 인식은 모델 연결 후.
- **임대사업소 주소·전화, 실시간 예약:** 확인하지 못해 출처 링크와 예약 기록 기능으로 대신했다.

## 로컬 실행

python3 -m http.server 8000
